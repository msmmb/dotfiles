Personal dotfiles for Linux (Manjaro GNOME)

## Included configurations

### Neovim / Vim
- Everything under `.config/nvim`
- Plugin setup and custom Lua/Vimscript

### Alacritty
- Custom terminal settings via `.custom_alacritty.py`
- Font, padding, theme and layout tweaks

### Tmux
- Session and window management
- Custom keybindings in `tmux.conf`

### Zsh + Powerlevel10k
- Zsh configuration in `.zshrc`
- Powerlevel10k prompt configuration (`.p10k.zsh`)
